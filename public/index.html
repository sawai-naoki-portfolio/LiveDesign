Canva のような画面でオーバーレイやウィジェットを作り、TikTok LIVE のギフト・フォロー・いいね・コメントで、アラートや紙吹雪、延長タイマーを動かせます。インストールは要りません。

できること

🎨

デザイン

図形・ペンツール・グラデーション・レイヤー・描画モード・アニメーション。日本語フォント入りの Google Fonts とテンプレートで、すぐに見栄えのする画面が作れます。

⚡

イベント → アクション

「100コイン以上のギフトで紙吹雪」「!jump で読み上げ」「フォローで延長タイマー +1分」を、ノーコードで組み立てられます。

📺

OBS・LIVE Studio に貼るだけ

URL を OBS のブラウザソースか TikTok LIVE Studio のリンクに貼るだけ。保存すると配信画面にその場で反映されます。

💬

配信ウィジェット

チャット・弾幕・アラート・いいね目標・ランキング・最近のイベント・タイマー。

🔑

パスワードは要りません

TikTok の @ID を入れるだけ。誰でも見られる LIVE のコメントやギフトを読むので、TikTok のパスワードは預かりません。

🎮

横配信にも縦配信にも

1920×1080 のゲーム実況から、1080×1920 の TikTok 縦配信まで。配信開始前の画面や延長タイマーのテンプレートもあります。

配信画面はこう映ります

3ステップではじめる

  1. 登録して、TikTok の @ID を入れるメールアドレスか Google / TikTok で登録。パスワードは預かりません。
  2. テンプレートからデザインを作るアラート・チャット・ゴールが入ったテンプレートを、好きな見た目に直します。
  3. URL を OBS か LIVE Studio に貼るあとは配信を始めるだけ。数十秒で自動的につながります。
